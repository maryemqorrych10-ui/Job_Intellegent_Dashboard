## Description

**Job Intelligent Dashboard** est une application intelligente conçue pour fournir un tableau de bord complet et intuitif de gestion d'emploi. Ce projet utilise des technologies modernes pour offrir une expérience utilisateur optimale.

## 🎯 Objectifs

- 📊 Visualiser les données relatives aux emplois
- 🤖 Analyser les tendances du marché du travail
- 📈 Suivre les statistiques en temps réel
- 🔍 Recherche intelligente et filtrage avancé
- 💾 Gestion efficace des données

## 🛠 Technologies

- **Backend**: Python 99.5%
  - Framework(s) recommandé(s): Flask/FastAPI
  - Traitement et analyse de données
  - API RESTful

- **Containerisation**: Docker 0.5%
  - Déploiement simplifié
  - Portabilité garantie

## 📋 Prérequis

- Python 3.8+
- Docker (optionnel)
- pip ou conda

## 🚀 Installation

### Option 1: Installation locale

```bash
# Cloner le repository
git clone https://github.com/maryemqorrych10-ui/Job_Intellegent_Dashboard.git
cd Job_Intellegent_Dashboard

# Créer un environnement virtuel
python -m venv venv
source venv/bin/activate  # Sur Windows: venv\Scripts\activate

# Installer les dépendances
pip install -r requirements.txt

# Lancer l'application
python app.py
```

### Option 2: Installation avec Docker

```bash
# Construire l'image Docker
docker build -t job-dashboard .

# Exécuter le conteneur
docker run -p 5000:5000 job-dashboard
```
